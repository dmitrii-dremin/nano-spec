# Changelog

## 0.1.0 — 2026-09-07

- Первая экспериментальная версия философии NanoSpec: достаточная постановка, контекст по задаче, рабочая запись и долгосрочные обязательства.
- Самодостаточные скиллы `nanospec-shape`, `nanospec-apply`, `nanospec-check`.
- Объявлен публичный контракт пакета и правила версионирования по SemVer 2.0.0.
- Подготовлен план практической проверки. Эффективность на реальных задачах ещё не подтверждена.
